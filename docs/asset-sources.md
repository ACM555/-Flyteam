## 使用规则

- 首屏摄影素材必须下载到本地，不直接依赖第三方图片地址。
- 登录页与工作台主图控制在 450KB 内，统一使用 WebP。
- 后续新增 Unsplash 或 Pexels 素材时，必须记录原始页面、作者、下载日期和许可链接。
- 未能确认授权来源的图片不得进入正式生产构建。
